🧾 PedidosExpress

Prototipo funcional de un sistema de pedidos en HTML puro, sin backend real: la base de datos es localStorage y la API es un enrutador simulado con latencia. Las tres apps comparten datos y traza en vivo — ábrelas en pestañas distintas y véalas hablarse.

🛒

Cliente

La tienda: catálogo con stock en vivo, carrito y checkout. Pagos con tarjeta simulados, seguimiento del pedido y avisos cuando el manager mueve tu pedido.
📊

Manager

El panel del negocio: KPIs, gestión de pedidos (avanzar estado, cancelar), inventario con reposición, registro de clientes y notificaciones. Se actualiza solo.
🛠️

DevTools

La caja negra abierta: el diagrama de arquitectura en vivo, la traza completa de cada llamada al "backend", los datos crudos y el botón de reinicio de la demo.
